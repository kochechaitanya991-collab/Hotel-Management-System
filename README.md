# Hotel-Management-System

A modern, full-featured Hotel Management and Billing Web Application migrated from Java to React and TypeScript on Vite.

## Features
- **Room Management & Inventory**: Standard default inventory (Rooms 101, 102, 201, 202, 301) with live occupancy status and filtering.
- **Room Booking**: Direct reservation workflow tracking guest name, contact phone, room number, and stay duration.
- **Check-Out & Bill Generation**: Instant itemized calculation of room stay duration, nightly rates, and total bills with printable receipts.
- **Active Bookings Tracker**: Overview of currently occupied rooms and checked-in guests.
- **Billing Records & Invoices**: Historical record of completed checkouts with receipts.
- **Original Java CLI Emulator**: Built-in interactive console mode that simulates the original command-line interface.

## Development
```bash
npm install
npm run dev
```
Runs on port 3000.
